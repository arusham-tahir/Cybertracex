About the Project

A Small Project with a Clear Purpose.

DESIGNED TO LEARN AND EXPLORE

CyberTraceX is a personal front-end project created to explore cybersecurity concepts through a simple, interactive website.

It brings together sample network activity, simulated security logs, and introductory security topics in one place.

The website is built with HTML5, CSS3, and JavaScript. Its purpose is to make security-related information easier to explore while developing practical web-development skills.

CyberTraceX is a learning and demonstration project, not a professional network-monitoring product.

Created by Arusham Tahir.

Privacy & Transparency

Privacy Policy.

This policy explains the basic privacy considerations for this demonstration website.

Last updated: October 2026

1. Information Collection

CyberTraceX does not include a custom account system or a data-submission form in this version. Its simulated dashboard and terminal do not intentionally collect personal information.

2. Network Activity

The terminal displays sample messages for demonstration. It does not perform live packet capture, scan devices, or transmit the displayed sample logs to a monitoring service.

3. Hosting and External Resources

This website is hosted on Vercel. The hosting provider may process technical information associated with website requests under its own privacy practices. Google Fonts is used to load typography and may receive technical request information when fonts are requested.

4. Cookies and Analytics

This version does not intentionally add analytics or advertising trackers. Hosting infrastructure or external services may have their own technical processing practices.

5. Changes to This Policy

This policy may be updated if the website adds new features, forms, analytics, or other services that change how information is processed.

6. Contact

For questions about CyberTraceX, use the contact links provided in the section above.
